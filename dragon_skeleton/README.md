# Procedural Dragon Skeleton

A beautiful procedural skeleton dragon animation built with Python and Pygame.

The dragon follows your mouse cursor using inverse kinematics, with realistic bone chains, procedural leg stepping, ribs, wings, and a detailed skull.

## Features

- **Inverse Kinematics Spine** — 22 vertebrae chain that smoothly follows the cursor
- **Procedural Leg Animation** — 4 legs with IK and automatic stepping
- **Detailed Skull** — Cranium, snout, horns, eye sockets, and teeth
- **Ribs & Wings** — Curved ribs along the spine with wing membrane struts
- **Tail with Spikes** — Tapering tail with spikes and arrow tip
- **Ambient Effects** — Subtle glow and dust particles

## Requirements

- Python 3.8+
- Pygame 2.5+

## Installation & Run

```bash
pip install -r requirements.txt
python dragon.py
```

## Controls

- **Move mouse** — Guide the dragon's head
- **ESC** — Quit
